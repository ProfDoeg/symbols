# Hebrew gematria: the standard method (mispar hechrechi): Research Dossier

## Basic identification

| Field | Identification |
|---|---|
| Primary name | גימטריה, *gimatriyya/gematria* |
| Standard method | מִסְפָּר הֶכְרֵחִי, *mispar hekhreḥi* (“necessary,” “absolute,” or standard number); also מִסְפָּר פָּשׁוּט, *mispar pashut* (“simple number”) |
| Script | Hebrew square script; historically applicable to earlier Hebrew/Aramaic letter forms once alphabetic numerical values had become established |
| Basic period | Alphabetic Hebrew numerals are securely attested in antiquity; interpretive gematria is explicitly documented in rabbinic literature of the first centuries CE |
| Core region | Roman Palestine and Sasanian Babylonia; subsequently the Jewish communities of Europe, North Africa, and the Islamic world |
| Comparative systems | Greek ἰσοψηφία, *isopsēphia*; Arabic حساب الجُمَّل, *ḥisāb al-jummal*, using the أبجد, *abjad*, order; Latin alphabetic reckoning |
| Operation | Assign a fixed value to each consonantal letter and add the values of all letters in the written word or phrase |
| Normal maximum letter | ת = 400 |
| Finals in the standard method | ך ם ן ף ץ normally retain the values of כ מ נ פ צ: 20, 40, 50, 80, 90 |
| Extended-finals method | In *mispar gadol*, “large number,” the five final forms may be assigned 500–900 |
| Reduction | None in standard *mispar hekhreḥi*. Reduction belongs to other named methods such as *mispar katan* |
| Evidentiary status | The table is historical; any alleged semantic or theological relationship between equal totals is an interpretation, not a consequence of the arithmetic alone |

| ה | he | 5 | ע | ayin | 70 |

This is a decimal alphabetic system: the first nine letters represent units, the next nine tens, and the remaining four hundreds. It rests on the same convention by which Hebrew letters function as ordinary numerals in dates, foliation, lists, biblical references, and manuscript notation. Gematria is therefore not the invention of arbitrary numbers for letters; it is the interpretive reuse of an alphabetic numeral notation.

### Extended finals: *mispar gadol*

| Final | Extended value |
|---:|---:|
| ך | 500 |
| ם | 600 |
| ן | 700 |
| ף | 800 |
| ץ | 900 |

**Documented later method:** In ordinary reckoning, final forms retain their base values. Treating them as 500–900 is a special extension usually called מִסְפָּר גָּדוֹל, *mispar gadol*. Calculations must identify explicitly which convention is being used.

## The system in detail

### 1. What is counted

Standard gematria counts the consonantal letters actually written:

- Consonants count once each.
- The five final letter-shapes ordinarily have the same values as their medial counterparts.
- Matres lectionis—א ה ו י used to indicate vowels—count because they are written letters.
- Masoretic vowel points, accents, cantillation signs, punctuation, and spaces do not count.
- A *qere* (“read”) and *ketiv* (“written”) may produce different totals; a responsible calculation states which one it uses.
- Defective and plene spellings matter. Thus דוד and דויד differ because the latter contains an additional י = 10.
- Divine names are normally calculated from their consonantal spelling, irrespective of how they are pronounced liturgically.
- A phrase is calculated by adding every letter in every included word. Spaces have no value.
- Definite articles, conjunctions, and prepositions count if written. הַשָּׂטָן and שָׂטָן therefore differ by ה = 5.
- Standard gematria does not reduce the result to a single digit.
- Orthographic normalization is not automatic. A calculation that silently modernizes ancient spelling is methodologically unstable.

### 2. What “equivalence” means

If two expressions have the same sum, later writers often say they are שָׁוִים בְּגִימַטְרִיָּא, “equal in gematria.” Arithmetic equality alone does not prescribe the claimed relationship. Sources use equality in several ways:

1. **Replacement:** an explicit number is interpreted as a name having that value.
2. **Allusion:** a word is said to hint at a number.
3. **Association:** two words with the same total are linked conceptually.
4. **Homiletic confirmation:** a previously held teaching is decorated or supported by a numerical correspondence.
5. **Mnemonic:** a total helps preserve a rule, date, or list.
6. **Prediction or revelation:** mystical and modern users sometimes treat the equality as information encoded by providence.
7. **Chronogram:** the words themselves intentionally record a year.

The first six are logically distinct. Equal totals prove only that the selected spellings, under the selected table, have equal sums.

### 3. Named Hebrew sub-methods

Terminology varies among manuals; names are not uniform across all periods.

| Method | Hebrew | Rule |
|---|---|---|
| Standard/absolute | מספר הכרחי / מספר פשוט | 1–400 table above |
| Large number | מספר גדול | Finals may continue 500–900; sometimes the expression also means an unreduced full sum |
| Small number | מספר קטן | Reduce every letter to its unit value: 10→1, 20→2 … 400→4 |
| Integral reduction | מספר קטן מספרי / reduction | Add the standard total’s digits, sometimes repeatedly |
| Ordinal number | מספר סידורי | Alef = 1 through tav = 22 |
| Filled spelling | מילוי, *milui* | Spell each letter-name in full and sum the resulting letters |
| First-letter value | מספר קדמי, a term used variously | In some sources, cumulative or “triangular” valuation; terminology is not fully stable |
| Collective addition | כולל, *kolel* | Add one for the whole word or expression; sometimes one per word |
| Squaring | ריבוע | Square letter values or expand a divine name progressively |
| Interchange | תמורה, *temurah* | Substitute letters by a fixed alphabetic scheme; strictly not additive gematria |
| First-last substitution | אתב״ש, *atbash* | א↔ת, ב↔ש, ג↔ר, etc. |
| Pairwise schemes | אלב״ם, אח״ס בט״ע, אטב״ח | Other traditional substitution alphabets |
| Acronymic interpretation | נוטריקון, *notariqon* | Read letters as initials or expand a word into a phrase; not numerical gematria proper |

The medieval and early-modern occult literature multiplied variants. This creates a major evidentiary hazard: a desired equality can sometimes be obtained by switching spellings, adding a *kolel*, using finals as 500–900, reducing digits, spelling letter-names out, or selecting a different substitution alphabet.

### 4. Etymology

**Documented uncertainty:** The Hebrew/Aramaic גימטריא is a Greek loan or Greek-derived technical term, but the precise derivation is disputed.

- A traditional scholarly proposal derives it from Greek γεωμετρία, *geōmetria*, “geometry,” apparently extended to calculation.
- Another derives it from a reconstructed or transposed γραμματεία, *grammateia*, relating to γράμμα, “letter,” or γραμματεύς, “scribe.”
- The 1906 *Jewish Encyclopedia* explicitly calls the etymology doubtful and records both positions. It also observes that גימטריא is not found in the Mishnah as a technical heading, though the practice appears in later tannaitic and amoraic material. [Jewish Encyclopedia, “Gemaṭria”](https://sefaria.jewishencyclopedia.com/articles/6571-gematria)

Claims that the word is Egyptian *khem-matria*, “measure of Egypt,” or that it derives from “gamma + tria” are **modern folk etymologies** without historical linguistic evidence.

## Worked examples

### A. Hebrew standard gematria

#### Eliezer = 318

אֱלִיעֶזֶר:

- א = 1
- ל = 30
- י = 10
- ע = 70
- ז = 7
- ר = 200

**1 + 30 + 10 + 70 + 7 + 200 = 318**

**Documented rabbinic interpretation:** Genesis 14:14 says Abram mobilized 318 trained retainers. Nedarim 32a preserves the opinion that this means Eliezer alone because אליעזר totals 318. Rashi repeats it: “It was Eliezer alone … and [318] is the numerical value of his name.” [Rashi on Genesis 14:14](https://www.sefaria.org/Rashi_on_Genesis.14.14.3)

**Earlier/lateral witnesses:** Genesis Rabbah 43:2 and related midrashim carry the identification. The *Epistle of Barnabas* 9.8 independently Christianizes the same biblical 318 through Greek numeral letters—300 as Τ, shaped like a cross, and 18 as ΙΗ, the beginning of Ἰησοῦς.

**Ancient Jewish criticism:** Ibn Ezra rejects the Eliezer inference as *derash*, observing that Scripture does not speak in gematria and that the procedure can turn any name to good or evil. [Ibn Ezra on Genesis 14:14](https://www.sefaria.org/Genesis.14.14-16?lang2=en&with=Ibn+Ezra)

#### “The Satan” = 364

הַשָּׂטָן:

- ה = 5
- ש = 300
- ט = 9
- ן = 50

**5 + 300 + 9 + 50 = 364**

**Documented text:** Yoma 20a attributes the calculation to Rami bar Ḥama. Satan may prosecute during 364 days but not on Yom Kippur, the remaining day of the 365-day solar year. [Yoma 20a](https://www.sefaria.org/Yoma.20a?with=Halakhah)

This depends on counting the article ה. שטן alone is 359.

#### יהיה = 30 and the ordinary Nazirite vow

יִהְיֶה:

- י = 10
- ה = 5
- י = 10
- ה = 5

**10 + 5 + 10 + 5 = 30**

**Documented legal use:** Rav Mattana uses יהיה in Numbers 6:5 to support the rule that an unspecified Nazirite vow lasts thirty days. The discussion occurs in Nazir 5a; medieval commentators state the arithmetic explicitly. [Nazir 5a](https://www.sefaria.org/Nazir.5a), [Meiri ad loc.](https://www.sefaria.org/Meiri_on_Nazir.5a)

This is important because gematria was not confined absolutely to nonlegal fantasy, although rabbinic authorities normally treated it as a weak support or mnemonic rather than an autonomous foundation for law.

#### Love = one = 13

אַהֲבָה, *ahavah*, “love”:

- א = 1
- ה = 5
- ב = 2
- ה = 5

**1 + 5 + 2 + 5 = 13**

אֶחָד, *eḥad*, “one”:

- א = 1
- ח = 8
- ד = 4

**1 + 8 + 4 = 13**

**Traditional/classic equivalence:** אהבה = אחד = 13. It is widely used in devotional and kabbalistic exposition to associate love and unity. The arithmetic is certain; attribution of an ancient doctrinal intention to the equation is not. The equation is much more conspicuous in medieval and modern teaching than in the earliest rabbinic strata.

#### The Tetragrammaton = 26

יהוה:

- י = 10
- ה = 5
- ו = 6
- ה = 5

**10 + 5 + 6 + 5 = 26**

**Documented conventional calculation:** 26 became an important divine number in kabbalistic literature and Jewish devotional symbolism. It is also 2 × 13, allowing later teachers to connect the divine name with אחד and אהבה. That theological synthesis is traditional interpretation, not intrinsic to the bare sums.

#### Serpent = Messiah = 358

נָחָשׁ, *naḥash*, “serpent”:

- נ = 50
- ח = 8
- ש = 300

**50 + 8 + 300 = 358**

מָשִׁיחַ, *mashiaḥ*, “messiah”:

- מ = 40
- ש = 300
- י = 10
- ח = 8

**40 + 300 + 10 + 8 = 358**

**Later kabbalistic/Hasidic equivalence:** נחש = משיח = 358 is interpreted in several ways: the redemptive transformation of primordial evil, the elevation of the serpent’s energy, or a warning that counterfeit redemption can resemble redemption numerically. The arithmetic is exact. Claims that Genesis’ author intentionally encoded the Messiah in נחש are **traditional or speculative**, not textually demonstrated.

#### Wine = secret = 70

יַיִן, *yayin*, “wine”:

- י = 10
- י = 10
- ן = 50

**10 + 10 + 50 = 70**

סוֹד, *sod*, “secret”:

- ס = 60
- ו = 6
- ד = 4

**60 + 6 + 4 = 70**

**Documented Talmudic example:** Eruvin 65a states that wine and secret were “given in seventy letters,” leading to נכנס יין יצא סוד, “when wine enters, a secret comes out.” [Sefaria’s text and arithmetic](https://www.sefaria.org/Sanhedrin.38a.3?with=Talmud)

The equation was elaborated by medieval kabbalists and the Zoharic tradition, where wine becomes a symbol of concealed Torah. The later mystical applications should not be backdated wholesale into the Talmudic saying.

### B. Greek isopsephy

Greek alphabetic numerals use 1–9, 10–90, and 100–900, including the archaic numeral signs stigma/digamma, koppa, and sampi.

#### Jesus = 888

Ἰησοῦς:

- Ι = 10
- Η = 8
- Σ = 200
- Ο = 70
- Υ = 400
- Σ = 200

**10 + 8 + 200 + 70 + 400 + 200 = 888**

**Documented second-century witness:** Irenaeus, *Against Heresies* I.15, reports and attacks Marcosian/Gnostic speculation that Jesus’ Greek name totals 888. The arithmetic predates later Christian “triple eight” symbolism. [Irenaeus, *Against Heresies* I.15](https://www.newadvent.org/fathers/0103115.htm)

#### Dove = 801

περιστερά, *peristera*, “dove”:

- π = 80
- ε = 5
- ρ = 100
- ι = 10
- σ = 200
- τ = 300
- ε = 5
- ρ = 100
- α = 1

**80 + 5 + 100 + 10 + 200 + 300 + 5 + 100 + 1 = 801**

**Documented Marcosian teaching:** Irenaeus reports the use of 801 because α and ω—1 and 800—frame the total, connecting the dove descending at Jesus’ baptism with Alpha and Omega. Irenaeus preserves the calculation as hostile evidence: it documents Marcosian practice while rejecting its theology.

#### “I love her whose number is 545”

Pompeian graffito:

> φιλῶ ἧς ἀριθμὸς φμεʹ  
> “I love [the woman] whose number is 545.”

φμεʹ is:

- φ = 500
- μ = 40
- ε = 5

**500 + 40 + 5 = 545**

**Documented inscription:** The graffito was buried by the eruption of Vesuvius in 79 CE and is direct archaeological evidence of popular numerical name-play. Because the woman’s name is unstated, the number does not uniquely recover it. Several Greek names could total 545.

#### Nero Caesar = 666

Using the Hebrew/Aramaic spelling נרון קסר, *Neron Qesar*:

- נ = 50
- ר = 200
- ו = 6
- ן = 50
- ק = 100
- ס = 60
- ר = 200

**50 + 200 + 6 + 50 + 100 + 60 + 200 = 666**

Without the second nun, נרו קסר:

**50 + 200 + 6 + 100 + 60 + 200 = 616**

**Scholarly reconstruction:** Most modern commentators regard Nero Caesar as the strongest historical solution to Revelation 13:18. It explains both the common 666 and the early 616 variant through Greek *Nerōn* versus Latin *Nero*. Irenaeus already knew the 616 variant but preferred 666 and proposed other Greek names totaling it. The explicit Nero solution is not preserved from the first century; one recent study notes that its recognizable modern formulation appeared in 1831. Thus:

- Revelation’s command to “calculate” is documented.
- The two ancient numerical readings are documented.
- Nero is a strong modern historical reconstruction, not an identification explicitly transmitted by John or Irenaeus.
- The ability to generate many other names totaling 666 is part of the coincidence problem.

[Cambridge discussion of 616](https://www.cambridge.org/core/journals/journal-of-ecclesiastical-history/article/abs/apocalyptic-number-616-and-the-donatist-church/0775DE1C87F329E3270E5A34AF356069)

### C. Arabic abjad

#### The Basmala = 786

بسم الله الرحمن الرحيم:

- ب 2 + س 60 + م 40 = 102
- ا 1 + ل 30 + ل 30 + ه 5 = 66
- ا 1 + ل 30 + ر 200 + ح 8 + م 40 + ن 50 = 329
- ا 1 + ل 30 + ر 200 + ح 8 + ي 10 + م 40 = 289

**102 + 66 + 329 + 289 = 786**

Or continuously:

**2 + 60 + 40 + 1 + 30 + 30 + 5 + 1 + 30 + 200 + 8 + 40 + 50 + 1 + 30 + 200 + 8 + 10 + 40 = 786**

**Documented calculation, later popular custom:** 786 is widely used, particularly in South Asian Islam, as a numerical emblem for the Basmala. It is not a Qurʾanic designation and writing “786” is not textually equivalent to reciting the formula. Muslim jurists have differed over the propriety of substitution. A contemporary fatwa confirms the arithmetic while denying that the number supplies the devotional merit of the words. [Banuri Town fatwa and full arithmetic](https://www.banuri.edu.pk/readquestion/144503101031/26-09-2023)

### D. Latin/Agrippan table

Agrippa’s *De occulta philosophia*, fully printed in 1533, gives tables correlating Hebrew, Greek, and Latin letters with numbers and celestial structures. A Latin extension commonly associated with Agrippa uses the premodern Latin alphabet:

| A | B | C | D | E | F | G | H | I |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |

| K | L | M | N | O | P | Q | R | S |
|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 10 | 20 | 30 | 40 | 50 | 60 | 70 | 80 | 90 |

| T | V | X | Y | Z |
|---:|---:|---:|---:|---:|
| 100 | 200 | 300 | 400 | 500 |

J is treated with I; U and W are historically variants or developments of V. Modern online “Jewish gematria” calculators often extend or rearrange this Latin table for the 26-letter English alphabet. That is **not Hebrew gematria**, despite the calculator label. Agrippa’s original is available in the [1533 Freiburg scan](https://dl.ub.uni-freiburg.de/diglit/agrippa1533) and [Internet Archive record](https://archive.org/details/DeOccultaPhilosophiaLoc1533).

## Origins: dated and placed

### Before alphabetic gematria: Mesopotamian precedents

#### Sargon II’s wall, ca. 717–706 BCE

An inscription of Sargon II says that the circumference of the wall of Dūr-Šarrukīn corresponded to the numerical value of his name. Modern summaries give 16,280 or 16,283 Assyrian cubits/units; the discrepancy reflects editions and reconstructions and should not be silently harmonized.

**Status: documented royal claim, disputed mechanism.** The inscription is often called the earliest gematria. It certainly documents a king deliberately relating a name-number to architecture. It does not demonstrate the later Hebrew or Greek alphabetic table, because Akkadian cuneiform was not an alphabet with one stable number assigned to each sign. The result is best classified as a Mesopotamian onomastic-number precedent, not automatically as Hebrew-style gematria. See Eckart Frahm’s study cited in the [Dūr-Šarrukīn summary](https://en.wikipedia.org/wiki/Dur-Sharrukin).

The wall establishes that name-number symbolism existed in Neo-Assyrian royal ideology. It does not settle how Greek isopsephy or Jewish gematria originated.

### Alphabetic numerals

Alphabetic gematria depends on a prior numeral notation in which letters already stand for numbers. Greek, Hebrew/Aramaic, Syriac, and Arabic systems share the old Semitic alphabetic order at crucial points. This suggests cultural transmission and common scribal ancestry rather than multiple wholly independent creations.

The historical sequence must distinguish:

1. ordering letters;
2. using letters as numerals;
3. calculating the sum of a word;
4. interpreting equal word-sums;
5. building mystical cosmology from such equivalences.

Evidence for one stage does not prove all later stages.

### Greek isopsephy, Hellenistic and Roman periods

The Greek Milesian/alphabetic numeral system was in use by the Hellenistic period. Clear word-number play appears in inscriptions, epigrams, oracles, magical texts, and Roman-period graffiti.

**Secure direct witnesses include:**

- isopsephic epigrams in which lines are deliberately made numerically equal;
- the Pompeian love graffiti before 79 CE;
- Revelation’s number of the Beast near the end of the first century;
- Suetonius’ report of a numerical anti-Nero graffito;
- Marcosian calculations reported by Irenaeus ca. 180 CE;
- magical papyri using strings of vowels, divine names, and numbered structures.

The Greek term ἰσόψηφος means “equal in counters/pebbles,” hence numerically equal.

### Was it Pythagorean?

**Tradition/disputed reconstruction:** Later writers associate number mysticism broadly with Pythagoras and the Pythagoreans. Pythagorean interest in numerical ratios is well documented. Direct evidence that Pythagoras devised the standard alphabetic word-sum system is absent.

Kieren Barry’s *The Greek Qabalah* argues strongly for Greek priority and gives Pythagorean materials an important role. It is a synthetic modern study, useful but not scholarly consensus on every point. Its publisher itself characterizes its Greek-origin conclusion as controversial. [Barry, *The Greek Qabalah*](https://books.google.com/books/about/The_Greek_Qabalah.html?id=w70rWN_-ANAC)

The common popular claim “Pythagoras invented numerology and assigned 1–9 repeatedly to names” is **modern invention by backward projection**. Ancient Pythagorean arithmology is not the modern English A=1, B=2 … I=9, J=1 system.

### Earliest Hebrew evidence

#### Hebrew Bible

**Negative finding:** No biblical passage identifies or explains a standard letter-value table, and no biblical author says that words should be added numerically. The 1906 *Jewish Encyclopedia* concluded that numerical gematria in the Bible “cannot be positively demonstrated.” [Jewish Encyclopedia](https://sefaria.jewishencyclopedia.com/articles/6571-gematria)

Proposed biblical examples—318/Eliezer, numerical structures in genealogies, divine-name totals, or architectural totals—are reconstructions. Some may be deliberate literary numerology, but literary number patterning is not automatically alphabetic gematria.

#### Second Temple period

Hebrew and Aramaic letters were used numerically by the late Second Temple and rabbinic periods. Revelation’s likely Hebrew spelling behind 666 shows that a Jewish/Christian author could expect a name to be “calculated,” but the precise language in which the audience was to calculate remains debated.

The *Epistle of Barnabas*, probably late first or early second century, interprets Abraham’s 318 through Greek numeral letters. It demonstrates Christian isopsephic exegesis of a Jewish scripture, not Hebrew אליעזר = 318.

#### Rabbinic literature, ca. third–sixth centuries in redaction

The Babylonian and Palestinian Talmuds and classical midrashim provide the first abundant, undisputed Jewish evidence:

- Nedarim 32a: Eliezer = 318.
- Yoma 20a: השטן = 364.
- Nazir 5a: יהיה = 30.
- Eruvin 65a: יין = סוד = 70.
- Shabbat 104a: alphabetic expositions and *atbash*.
- Sanhedrin 22a and Jeremiah’s ששך/לב קמי traditions: substitution alphabets.

These sources document gematria as a recognized exegetical procedure, but they were compiled over centuries. A statement placed in the mouth of a named tanna or amora must be dated cautiously: it may preserve early teaching, later redaction, or both.

### The Thirty-Two Rules

The *Baraita of the Thirty-Two Rules* is traditionally attributed to Rabbi Eliezer ben Yose ha-Gelili, a second-century tanna. Gematria is conventionally called its twenty-ninth rule, although some enumerations count it as twenty-eighth because textual divisions differ.

**Text-critical caution:** The work survives in later compilations and has a complex textual history. Some scholars have assigned substantial portions to a much later period, even as late as the tenth century. Therefore:

- “Gematria is the twenty-ninth of Rabbi Eliezer’s rules” is a documented medieval textual tradition.
- “The extant Baraita was written intact by Rabbi Eliezer in the second century” is disputed.
- The rule’s examples overlap genuinely early rabbinic material, so late compilation does not mean every component is late.

[Sefaria’s *Baraita of the 32 Middot*](https://www.sefaria.org/Otzar_Midrashim%2C_Baraita_of_The_32_Midot_of_Aggadah%2C_Introduction)

### Sefer Yetzirah

*Sefer Yetzirah*, compiled in some form between late antiquity and the early medieval period, describes creation through “thirty-two wondrous paths”: ten *sefirot belimah* and twenty-two “foundation letters.” It divides the letters into mothers, doubles, and simples and instructs the reader to engrave, hew, weigh, permute, and combine them. Its 231 “gates” are the possible unordered pairings of twenty-two letters.

**Important distinction:** *Sefer Yetzirah* is foundational for Jewish letter mysticism and permutation, but it is not principally a handbook of standard additive gematria. Later readers absorbed it into gematric cosmology. [Sefer Yetzirah 1:1](https://www.sefaria.org/Sefer_Yetzirah.1.1?lang=bi&with=Kabbalah), [2:2 and the 231 gates](https://www.sefaria.org/Sefer_Yetzirah.2.2?lang=en&with=Notes)

### Marcosians and Irenaeus, ca. 180 CE

Irenaeus’ *Adversus haereses* I.14–16 is the earliest extensive description of a Christian group’s alphabetic theology. Marcus and his followers treated Greek letters, sounds, syllables, aeons, and numbers as structures of the divine Pleroma. Irenaeus records Jesus = 888 and dove = 801 but mocks the freedom with which they choose spellings and numerical groupings.

This is valuable in two ways:

- as primary evidence for second-century Christian/Gnostic letter-number speculation;
- as an ancient statement of the methodological criticism still made today: flexible rules can manufacture results.

[Irenaeus I.14](https://www.newadvent.org/fathers/0103114.htm), [I.15](https://www.newadvent.org/fathers/0103115.htm)

### Pistis Sophia

The Coptic *Pistis Sophia*, probably compiled in the third or fourth century, preserves elaborate numerical cosmology, strings of sacred names, emanational orders, and Greek letter-number material embedded in Coptic transmission.

**Status:** documented late-antique Christian esotericism, but not a single stable “Pistis Sophia gematria table.” Some modern occult accounts regularize its corrupt or opaque letter strings into systems more definite than the manuscripts permit. It belongs to the history of alphanumeric cosmology, not directly to the genealogy of *mispar hekhreḥi*.

### Arabic abjad inheritance

The Arabic *abjad* order—أبجد هوز حطي كلمن سعفص قرشت—preserves the old Northwest Semitic alphabetic sequence more closely than the modern Arabic pedagogical order. The basic values proceed from 1 to 1000.

**Scholarly reconstruction:** Arabic alphabetic numerals developed from the late-antique Semitic scribal environment, with Nabataean Aramaic especially important for the ancestry of Arabic script. It is more accurate to speak of inheritance and adaptation than of a direct borrowing from medieval Hebrew gematria.

Arabic terms include:

- حساب الجُمَّل, *ḥisāb al-jummal*, “calculation of the total”;
- حساب أبجد, *ḥisāb abjad*;
- علم الحروف, *ʿilm al-ḥurūf*, “science of letters”;
- أوفاق, *awfāq*, numerical or letter magic squares.

Chronograms became especially prominent in Persian and Ottoman literature from the later Middle Ages. The genre was already known earlier, but Persian abjad chronograms became extremely popular in the ninth/fifteenth century. [Encyclopaedia Iranica, “Chronograms”](https://www.iranicaonline.org/articles/chronograms-pers/), [“Mādda Tārīkh”](https://www.iranicaonline.org/articles/madda-tarik-chronogram/)

### Medieval Jewish expansion

#### Ashkenazi Hasidim

The twelfth- and thirteenth-century Hasidei Ashkenaz, including Judah he-Hasid and Eleazar of Worms, used divine-name calculations, prayers counted by words and letters, permutations, and elaborate gematriot. Numerical correspondences could regulate the exact wording of prayer and disclose relations among angelic names.

#### Early Kabbalah and the Zohar

The thirteenth-century kabbalists of Provence and Spain integrated letter-number interpretation into a symbolic map of the *sefirot*. The Zohar, largely composed in late thirteenth-century Castile, repeatedly uses gematria, letter shapes, acrostics, and substitutions.

**Documented use; disputed attribution:** Traditional Judaism attributes the Zohar to Rabbi Shimon bar Yoḥai in the second century. Historical scholarship, beginning well before Scholem and developed decisively by him, locates its principal composition around Moses de León’s circle in late-thirteenth-century Castile. Individual older traditions may be embedded within it.

#### Abraham Abulafia, 1240–after 1291

Abulafia’s prophetic or ecstatic Kabbalah made צירוף, *tzeruf*, letter combination, central to contemplative practice. His methods included:

- permutation of divine names;
- vocalization and controlled pronunciation;
- breathing and bodily motions;
- gematria;
- *notariqon* and substitutions;
- multilingual equivalences across Hebrew, Greek, Latin, Italian, and Arabic.

For Abulafia, these were not merely literary puzzles. Breaking ordinary language into letters and recombining it was a disciplined path toward prophetic consciousness. Scholem called this current “prophetic” or “ecstatic” Kabbalah; Moshe Idel substantially revised and expanded the analysis, emphasizing technique, experience, and multilingualism. [Scholem, “The Name of God and the Linguistic Theory of the Kabbalah”](https://www.ma.huji.ac.il/~kazhdan/Shneider/hermeneutics/Scholem_Name_of_God.pdf)

#### Jacob ben Asher, the Baal Ha-Turim, ca. 1269–1343

Jacob ben Asher’s short Torah commentary, written in the early fourteenth century, is the great systematic monument of medieval biblical gematria. Its compact opening notes connect spellings, adjacent passages, masoretic peculiarities, and equal totals.

In his introduction he says that he included “some *peraferot* and gematriot and reasons of the Masorah, to draw the heart.” This is a revealing self-description: gematria is an attractive homiletic ornament and associative aid, not necessarily the plain meaning of Scripture.

Examples traditionally attached to his commentary include multiple expansions of בראשית and the equation תורה = 611:

תורה:

- ת = 400
- ו = 6
- ר = 200
- ה = 5

**400 + 6 + 200 + 5 = 611**

A homily then says Moses communicated 611 commandments, while the first two of the traditional 613 were heard directly from God. The arithmetic is clear; the count of 613 itself is a rabbinic-medieval enumeration whose exact division varies among authorities.

### Hasidism and the Baal Shem Tov

From the eighteenth century onward, Hasidic teachers used gematria within sermons on divine immanence, prayer, repentance, and the spiritual meaning of names. Teachings circulated orally before being written by disciples, so precise attribution to Israel ben Eliezer, the Baal Shem Tov (ca. 1700–1760), often requires caution.

**Documented tradition, attribution sometimes secondary:** Collections such as *Tzavaʾat ha-Ribash*, *Keter Shem Tov*, and later Hasidic homiletics transmit gematric teachings associated with the Baal Shem Tov. They are evidence for Hasidic reception, but not stenographic records.

Chabad/Lubavitch discourse uses gematria alongside philosophical exposition, especially totals involving אחד, אהבה, יהוה, בן, מה, אדם, and the divine names. Modern Chabad educational material accurately describes the mechanics but often presents traditional antiquity more confidently than historical criticism warrants. [Chabad overview](https://www.chabad.org/library/article_cdo/aid/5541252/jewish/What-Is-Gematria.htm)

### Renaissance Christian Cabala and Agrippa

Pico della Mirandola, Johannes Reuchlin, Francesco Giorgi, and other Renaissance Christian cabalists adapted Jewish Kabbalah to Christian theology. Hebrew names and numerical correspondences were used to support Trinitarian and Christological readings.

Heinrich Cornelius Agrippa’s *De occulta philosophia* circulated in an early version in 1510 and appeared in its authorized expanded form in 1533. It synthesized:

- planetary magic;
- Pythagorean and Neoplatonic number symbolism;
- Hebrew divine names;
- Greek and Latin letter-number correspondences;
- magic squares and celestial seals.

John French’s 1651 English translation helped transmit the material into Anglophone occultism.

### Reformation polemic and 666

The “number of the Beast” became a polemical machine. Protestant authors calculated papal titles, *Lateinos*, “Roman,” and variations on *Vicarius Filii Dei*; Catholic polemicists answered with Protestant names. Spelling choices, treatment of U/V and I/J, language changes, title selection, and omission of nonnumeral letters made rival totals easy to obtain.

**Documented reception, weak identification method:** These sums are historically real as polemic. They do not independently identify the subject of Revelation, because the candidate pool and orthography were selected after the target had been chosen.

### Hebrew, Arabic, Persian, Ottoman, and Latin chronograms

A chronogram is stronger evidence of intentionality than a retrospective gematria because the author signals that a line contains a date and composes it for that purpose.

#### Hebrew

Jewish chronograms appear on:

- tombstones;
- synagogue inscriptions;
- title pages and colophons;
- commemorations of fires, expulsions, births, and deaths.

Hebrew dates often omit the millennium, marked by לפ״ק, *li-frat katan*, “according to the minor era.” A biblical phrase is chosen whose letter total gives the year. Enlarged, dotted, or otherwise marked letters may specify which characters count.

#### Arabic and Persian

Persian مادهٔ تاریخ, *mādda-ye tārīkh*, and simply تاریخ, *tārīkh*, became a major poetic art. A final hemistich commonly yields the Hijri year. Manuals distinguish explicit dates, fully numerical abjad dates, and riddling *tārīkh-e taʿmiya*. The practice flourished especially from the fifteenth century through the Qajar period. [Iranica](https://www.iranicaonline.org/articles/chronograms-pers/)

#### Ottoman Turkish

Ottoman poets developed highly elaborate tarih verses for accessions, victories, mosques, fountains, schools, births, and deaths. Court poets could become renowned for extemporaneous chronograms. Persian models were foundational, but Ottoman Turkish developed its own institutional and architectural setting.

#### Latin

Latin chronograms usually count Roman-numeral letters—I, V, X, L, C, D, M—embedded and often capitalized within an inscription. This is not the same as Agrippa’s full Latin alphabet table. It is a separate chronogram convention using ordinary Roman numeral signs.

## Uses

### Exegesis and homily

Rabbinic gematria generally supplements, illustrates, or mnemonically reinforces interpretation. It can:

- turn a written number into a name;
- infer a number from a word;
- associate words with equal values;
- support a rule already known by tradition;
- weave distant verses into a sermon.

The medieval distinction between פשט, plain/contextual sense, and דרש, homiletic exposition, is crucial. Ibn Ezra’s criticism of Eliezer = 318 shows that Jewish tradition itself never spoke with one voice about evidentiary weight.

### Kabbalistic theology

Kabbalists use totals to correlate:

- divine names;
- *sefirot*;
- angels;
- biblical persons;
- limbs and cosmic structures;
- prayers and ritual actions;
- creation and redemption.

A number may serve as an intersection in a symbolic network rather than as a proposition capable of historical proof.

### Letter permutation and meditation

Abulafian *tzeruf* transforms letters through recitation, vocalization, breathing, visualization, writing, and combination. Gematria participates by suggesting which words or names may substitute for one another. Here “equivalence” is experiential and contemplative, not merely exegetical.

### Prayer-text stabilization

Ashkenazi pietists counted words and letters in prayers. A prayer’s traditional wording could be defended because its count corresponded to a divine name, biblical verse, or angelic structure. Variant liturgies therefore changed not only semantics but sacred arithmetic.

### Amulets and practical magic

Jewish amulets may combine:

- divine and angelic names;
- biblical verses;
- letter permutations;
- seals;
- magic squares;
- numerical totals.

*Sefer Raziel ha-Malakh* is a medieval compilation, first printed in Amsterdam in 1701, drawing on older Jewish magical and cosmological materials. Traditional legend makes it a book revealed by the angel Raziel to Adam. That is **legend**, not manuscript history. Some contents are much older than the printed compilation, but the book as a single antediluvian artifact is unsupported.

### Greek magical papyri

The Greek and Demotic magical papyri, chiefly preserved from Roman Egypt, use vowel sequences, voces magicae, divine names, geometric arrangements, and numbered repetitions. Not every numerical prescription is isopsephy, but the papyri show the broader environment in which letters, sounds, deities, and numbers were interchangeable ritual powers.

### Islamicate letter science and *awfāq*

Islamicate occult sciences combined abjad values with:

- Qurʾanic verses and divine names;
- astrology;
- talismans;
- magic squares;
- planetary correspondences;
- letter cosmology.

Aḥmad al-Būnī, especially the textual tradition associated with *Shams al-maʿārif*, became central. Authorship and textual layers are complex: the printed *Shams* should not be assumed identical to a single thirteenth-century autograph.

The Latin *Picatrix*, translated in thirteenth-century Castile from Arabic *Ghāyat al-ḥakīm*, transmitted astral magic, images, suffumigations, and numerical structures. It is part of the common Mediterranean occult environment, though it is misleading to call every calculation in it “gematria.”

### Prophecy and apocalyptic polemic

Revelation 13:18 generated identifications of emperors, popes, reformers, rulers, nations, technologies, and modern politicians. The procedure is most persuasive when:

- the language is historically appropriate;
- spelling is independently attested;
- the numerical variant is explained;
- the candidate fits the literary and political context;
- rules were fixed before calculation.

The Nero hypothesis meets these tests better than most later candidates but remains a reconstruction.

### Poetry and commemoration

Persian and Ottoman chronograms are intentional constrained writing. Their success was judged artistically: the dating hemistich had to be meaningful, elegant, metrically correct, and numerically exact. This is not “accidental coincidence”; the poet deliberately engineered the sum.

### Modern ceremonial occultism

The Hermetic Order of the Golden Dawn, founded in Britain in 1888, integrated Hebrew gematria into a correspondence system connecting:

- Hebrew letters;
- the twenty-two Tarot trumps;
- paths on the Tree of Life;
- planets, zodiac, and elements;
- deities and magical weapons;
- colors, perfumes, stones, and visionary grades.

Aleister Crowley and Allan Bennett compiled *Sepher Sephiroth*, a dictionary of Hebrew words arranged by numerical total. Crowley’s *Liber 777*, first published in 1909, expanded Golden Dawn correspondence tables. Its title also evokes the gematria of a phrase from *Sefer Yetzirah*:

אחת רוח אלהים חיים, conventionally calculated as 777 under the spelling used by Crowley.

Crowley treated gematria as both a comparative index and a means of interpreting visionary or scriptural language. [Crowley, *777* scan](https://hermetic.com/_media/93beast.fea.st/files/section1/777/liber_777.pdf)

### Modern popular numerology

#### “Pythagorean numerology”

The modern repeated 1–9 English table:

A=1, B=2 … I=9; J=1 … R=9; S=1 … Z=8

is **not documented as a system devised by Pythagoras**. It developed in the modern occult/New Thought environment. L. Dow Balliett (1847–1929) was a major organizer and popularizer around the turn of the twentieth century. Her books connected names, birth dates, musical vibration, colors, and character.

#### “Chaldean numerology”

The English name-number table popularized as “Chaldean” assigns 1–8 according to claimed sound vibrations and commonly leaves 9 sacred. Cheiro—William John Warner, Count Louis Hamon (1866–1936)—popularized it through books on palmistry, astrology, and numbers.

**Modern invention/branding:** No cuneiform Chaldean text contains Cheiro’s English-letter table. The label invokes Babylonian prestige; the scheme is a nineteenth-/early-twentieth-century occult adaptation.

#### The word “numerology”

The terminology became common only in the early twentieth century. Ancient number symbolism, alphabetic numerals, arithmology, and modern personality “numerology” should not be treated as one unchanged discipline.

### English Qabalah experiments

Crowley’s *Book of the Law* 2:55 says an “order & value of the English Alphabet” will be obtained. Crowley did not establish a generally accepted solution.

James Lees devised the ALW or New Aeon English Qabalah in November 1976. Ray Sherwin first reported it publicly in *The New Equinox* in 1979; Lees published further material in 1981–82. It is therefore a **documented modern invention**, despite its presentation by practitioners as a discovery or revelation. [History and values](https://en.wikipedia.org/wiki/English_Qaballa)

Other English ciphers—English ordinal, reduction, reverse ordinal, primes, “Satanic,” and “Jewish”—are modern calculator systems. Their names do not establish ancient provenance.

### Internet gematria and conspiracy culture

Sites such as Gematrinator let users compare phrases under dozens or hundreds of ciphers. This creates new practices:

- searching large databases for equal totals;
- switching among ciphers after seeing the result;
- inserting or deleting articles and punctuation;
- treating news dates as numbers;
- connecting unrelated events through matching totals.

Gematrinator itself now labels one formerly “Jewish” English cipher “Latin,” acknowledging that it is not Hebrew gematria. [Gematrinator FAQ](https://gematrinator.com/faq)

These tools are genuine contemporary cultural artifacts. Their calculations may be arithmetically correct under their own rules, but claims of ancient Jewish authority are commonly **modern mislabeling**.

### Torah codes as a cousin, not gematria proper

Doron Witztum, Eliyahu Rips, and Yoav Rosenberg’s 1994 *Statistical Science* paper claimed unusually close equidistant-letter sequences in Genesis. ELS selects letters at a constant interval; it does not assign numbers to letters and sum words. It is therefore not gematria, although it shares the conviction that the exact consonantal text carries hidden formal structures.

The authors reported a randomization probability of 0.00002. [Original 1994 paper](https://users.cecs.anu.edu.au/~bdm/dilugim/WRR94.pdf)

Brendan McKay, Dror Bar-Natan, Maya Bar-Hillel, and Gil Kalai’s 1999 analysis argued that the result was “fatally defective” and depended on discretionary choices in spellings, appellations, and experimental design. Comparable codes could be generated in nonbiblical texts. [Hebrew University record](https://cris-test.huji.ac.il/en/publications/solving-the-bible-code-puzzle), [McKay’s documentation](https://users.cecs.anu.edu.au/~bdm/codes/torah.html)

The controversy is an unusually clear modern demonstration of the “researcher degrees of freedom” problem that also affects gematria.

### Literature

#### Borges

Jorge Luis Borges repeatedly engaged Jewish mysticism, the divine name, the combinatorial alphabet, and the idea that the universe might be a decipherable book. “The Golem,” “The Aleph,” “The Library of Babel,” “The Writing of the God,” and his lectures on Kabbalah participate in this conceptual field. Specific claims that Borges constructed entire works by standard gematria require case-by-case textual proof; the general kabbalistic influence is documented more securely than many numerical reconstructions.

#### Georges Perec and Oulipo

Perec and Oulipo used constrained composition, combinatorics, lipograms, enumerations, grids, and catalogues. Scholarship compares this with kabbalistic permutation and gematria, especially in Perec’s Jewish autobiographical context. Such comparison is interpretive. Oulipian constraints are documented authorial procedures; a hidden gematria should not be asserted without manuscripts or reproducible textual evidence.

#### James Joyce

Joyce’s works contain extensive number play—especially 32, 40, 1132, and cyclical numbers in *Ulysses* and *Finnegans Wake*. Some commentators use “gematria” loosely for Joyce’s numerical puns. Direct dependence on Hebrew *mispar hekhreḥi* is much harder to establish. “Joyce’s numbers” belong securely to literary numerology; particular Hebrew-gematria readings remain disputed unless supported by notes or exact multilingual arithmetic.

## Controversies and disputes

### 1. Mesopotamia, Greece, or Israel?

There is no single uncontested answer because “origin” can mean several things.

- **Mesopotamia:** Earliest surviving name-number/architecture analogy: Sargon II. But it is not based demonstrably on alphabetic letter values.
- **Greece:** Earliest abundant and unmistakable word-sum practice using a fully developed alphabetic numeral system.
- **Israel/Judaism:** Independent rabbinic form with Hebrew letters, securely documented in late antique texts; possible earlier practice is plausible but not directly established.
- **Common scribal background:** Greek and Semitic alphabetic numerals emerged amid intense eastern Mediterranean contact. Direct one-way borrowing is difficult to prove.

Barry favors Greek priority. Traditional Jewish accounts sometimes treat gematria as Sinaitic or embedded in creation. Those are theological traditions, not conclusions from dated inscriptions.

### 2. Does Genesis 14:14 prove biblical gematria?

No—not by itself.

The fact that אליעזר totals 318 is real. But Eliezer appears in Genesis 15:2, not in the battle verse, and 318 is a plausible literal household-retainer count within the narrative. The interpretation is securely rabbinic; authorial intention in Genesis is disputed.

Ibn Ezra’s objection remains methodologically exact: a sufficiently large vocabulary permits many names to match a number.

### 3. The Pythagorean claim

Ancient Pythagoreans assigned metaphysical importance to number. There is insufficient evidence that Pythagoras invented:

- Greek alphabetic numerals;
- systematic word-sum isopsephy;
- the modern repeated 1–9 name chart;
- personality readings from English names and birthdays.

Calling modern English numerology “Pythagorean” is a lineage claim constructed by modern occultists.

### 4. The “Chaldean” claim

Ancient Babylonian and Chaldean scholars practiced sophisticated sexagesimal mathematics, astronomy, omens, and name symbolism. No surviving cuneiform manual gives Cheiro’s English phonetic table. “Chaldean numerology” is a modern occult brand built from genuine Babylonian prestige and later alphabetic practices.

### 5. Coincidence and the size of the search space

With twenty-two letters but only a few hundred commonly occupied totals, collisions are inevitable.

For a word of length \(n\), even before semantic selection there are \(22^n\) possible letter strings. Natural-language constraints reduce this enormously, but many dictionary words still share each common total. Short totals are especially crowded.

A claim becomes weaker when the investigator may freely choose:

- Hebrew, Aramaic, Greek, Latin, or English;
- full, defective, or modern spelling;
- title, personal name, surname, or transliteration;
- inclusion of ה, ו, particles, or honorifics;
- standard, ordinal, reduced, filled, reverse, or final-letter values;
- one or more *kolel* additions;
- multiplication, squaring, or concatenation;
- a target discovered only after searching.

A convincing intentional gematria needs controls: a fixed text, fixed spelling, historically attested table, independently motivated candidates, and preferably a source that signals the calculation.

Chronograms satisfy these conditions far better than open-ended internet searches.

### 6. Textual instability

Gematria is unusually sensitive to scribal variation. A single ו or י changes the total by 6 or 10. Hebrew biblical manuscripts are highly stable in the medieval Masoretic tradition, but differences exist among the Masoretic Text, Samaritan Pentateuch, Dead Sea Scrolls, ancient quotations, and later editions. A purported primordial code that depends on one medieval orthography must explain why that textual form is privileged.

### 7. Gematria as proof in Jewish law

The Talmud sometimes uses gematria in legal discussions, but later methodological tradition commonly treats it as an *asmakhta*—support or mnemonic—unless backed by received tradition. It is misleading both to say “gematria never affects halakhah” and to say “any equal total creates a law.”

### 8. Scholem, Idel, Dornseiff, Barry, Weinreb, and Kaplan

#### Franz Dornseiff

*Das Alphabet in Mystik und Magie* (1922) remains a foundational comparative collection on Greek, Jewish, Christian, and magical alphabet speculation. Its strengths are philological breadth and primary materials; its historical syntheses predate much subsequent manuscript discovery. [Complete scan](https://iapsop.com/ssoc/1922__dornseiff___das_alphabet_in_mystik_und_magie.pdf)

#### Gershom Scholem

Scholem situated gematria within a larger Jewish “mysticism of language.” He distinguished early letter speculation, medieval theosophical Kabbalah, Abulafian ecstatic combination, and later practical systems. His historical work undermined uncritical claims that the entire Zohar or medieval Kabbalah came unchanged from the tannaitic period.

#### Moshe Idel

Idel criticized overly linear or exclusively textual accounts. He stressed multiple kabbalistic models, practical techniques, oral transmission, ecstatic experience, and multilingual experimentation. In Abulafia, gematria is one operation within a complex contemplative technology.

#### Kieren Barry

Barry assembled Greek evidence and argued that what is called “Qabalah” has substantial Greek antecedents. His catalog of isopsephy is valuable; the claim that Greek priority explains Hebrew Kabbalah in a simple genealogical line is more controversial.

#### Friedrich Weinreb

Weinreb presented Hebrew words and biblical narratives through expansive numerical symbolism. His work has devotional influence but is not a standard historical-critical authority. Numerical insight and historical proof are frequently blended.

#### Aryeh Kaplan

Kaplan’s *Sefer Yetzirah* edition and meditative writings made technical letter mysticism accessible in English. He combines textual comparison, traditional commentary, reconstruction, and practical interpretation. His historical dates and meditation reconstructions should be distinguished from manuscript consensus; they are influential syntheses, not neutral critical editions.

### 9. Forgeries and pseudepigrapha

Several kinds must be distinguished:

- **Ancient/medieval pseudepigraphy:** *Sefer Raziel* attributed to Adam or Solomon; Zohar attributed to Shimon bar Yoḥai. These are traditional authorizations, not necessarily modern commercial fraud.
- **Renaissance prisca-theologia claims:** occult texts presented as remnants of primordial wisdom.
- **Modern fabricated antiquity:** “Pythagorean” and “Chaldean” English tables marketed as unchanged ancient systems.
- **Calculator mislabeling:** a Latin/English stepped cipher called “Jewish gematria.”
- **Retrofitted discoveries:** numerical patterns found after extensive searching but presented as though they uniquely predicted the target.
- **False quotations:** internet claims that a rabbi, Pythagoras, or an ancient tablet taught a modern equation without a cited text.

Absence of a manuscript, inscription, or identifiable edition is affirmative evidence against claims of documented antiquity, though not proof that no oral or lost practice ever existed.

### 10. Legend and fact

Legends are historically important even when not factual:

- Raziel gave Adam a celestial book.
- Abraham knew the mysteries of letters.
- Moses received gematria at Sinai.
- *Sefer Yetzirah* teaches creation of a golem.
- Pythagoras inherited Egyptian temple numerology.
- “Chaldean” sages transmitted Cheiro’s table.
- English Qabalah was revealed rather than devised.

Each legend tells us how later communities authorized a practice. None supplies the dated evidence that a historical reconstruction requires.

## Open questions

1. When exactly did Hebrew letters first receive the complete 1–400 numeral table?
2. Did interpretive Hebrew word-summing develop independently, through Greek influence, through a shared Aramaic scribal milieu, or through several channels?
3. Is any proposed biblical gematria sufficiently constrained to establish authorial intention?
4. What is the earliest manuscript form of the Twenty-Nine/Thirty-Two Rules, and which strata are tannaitic?
5. How much older material survives inside *Sefer Yetzirah* and the Zohar?
6. Which gematriot attributed to the Baal Shem Tov can be traced to the earliest disciple manuscripts?
7. When does 786 first appear as a conventional written substitute for the Basmala, rather than merely as a possible calculation?
8. What are the earliest securely dated Arabic and Persian abjad chronograms?
9. How much of the printed *Shams al-maʿārif* descends from al-Būnī, and how much is later accretion?
10. Can statistical models estimate expected Hebrew word-sum collisions while respecting morphology, spelling frequency, and semantic selection?
11. How should intentional chronograms, constrained poetry, and open-ended “discovery” gematria be compared quantitatively?
12. Which numerical structures in Borges, Perec, and Joyce are authorially documented, and which are reader constructions?
13. At what point did online calculators begin calling the Agrippan/Latin cipher “Jewish gematria,” and through which websites did the label spread?
14. How have search engines and large phrase databases changed the social meaning of numerical coincidence?

## Conclusions

Standard Hebrew gematria is a clearly defined arithmetic built upon historical Hebrew alphabetic numerals: א = 1 through ת = 400, with ordinary final letters retaining their base values. Its arithmetic is stable when spelling and method are fixed. Its interpretations are not.

The earliest unambiguous Jewish uses are rabbinic, though alphabetic numerals and Mediterranean word-number play are older. Sargon II provides a real Mesopotamian name-number precedent, but not the Hebrew table. Greek isopsephy supplies the earliest abundant direct evidence for alphabetic word sums. The relationship among Greek, Hebrew/Aramaic, and later Arabic practices is best understood as cultural transmission within interconnected scribal worlds, not as a securely proven invention by one famous individual.

Within Judaism, gematria moved from rabbinic homily into medieval prayer mysticism, Kabbalah, Abulafian meditation, Zoharic symbolism, the Baal Ha-Turim’s commentary, Hasidic preaching, amulets, and modern popular teaching. Parallel systems flourished in Christian exegesis, Islamicate letter science, Persian and Ottoman chronograms, Renaissance magic, and modern occultism.

The history includes rigorous intentional compositions, devotional interpretation, hostile polemic, inspired speculation, pseudepigraphic legend, modern invention, and unrestricted coincidence hunting. All are part of the dossier, but they are not the same kind of evidence.
